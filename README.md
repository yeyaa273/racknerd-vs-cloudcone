## 稳定性：一次必须知道的安全事件，和一组实测数据

先说事件。2026 年 1 月下旬，CloudCone 洛杉矶 DC1 的低价 VPS 基础设施遭到勒索软件式攻击，攻击利用了第三方虚拟化平台 Virtualizor 的漏洞，部分洛杉矶宿主节点磁盘损坏，受影响用户的数据无法恢复。CloudCone 之后的处理算得上透明：发布完整事件报告、轮换全部 API 密钥和凭据、加固 IP 级访问控制、从干净环境重建部署网关，并开始把业务迁移到自研虚拟化平台。受影响客户拿到了一个月额度补偿、续费时两个月的免费延长，以及最长一年的备份服务五折。密苏里和弗吉尼亚机房完全未受影响。

这件事的教训对两家都成立：再便宜的 VPS 也要自己做异地备份。如果它让你对预算 VPS 整体犯嘀咕，RackNerd 2026 年至今没有可类比的重大事故记录，属于更保守的选择。

同一篇测评还给出了性能层面的数据：RackNerd 同一台机器的 Geekbench 跑分在不同时段波动明显，是超售的典型信号，实测正常运行时间在 95%–99% 之间浮动，部分节点仍是标准 SSD，I/O 在 100–200 MB/s；CloudCone 的云架构资源调度更平稳，多数节点已升级 NVMe，读写约为前者的 2–3 倍，故障节点支持自动迁移，测评中的正常运行时间接近 99.9%。跑脚本、代理和学习环境，RackNerd 的波动基本无感；跑需要持续在线的网站或 API，这些差距会被放大。顺带一提，LowEndTalk 社区对 RackNerd 客服响应的评价相当一致：平均 10 分钟以内的回复速度，在低价档里算快的。

## 条款里才写清楚的细节：备份、取消和退款

两家都是无托管服务，系统、应用、安全和备份全归你自己管，但条款层面有几个容易踩坑的点。

**RackNerd**：VPS 默认不含托管备份，想备份得自己写脚本传到外部存储；取消服务要在续费前至少 5 天通过客户区提交，取消后数据会被删除。这条只写在条款里，忘了提交就会自动续费。

**CloudCone SC2**：有 7 天退款保障；销毁实例的操作不可逆，数据随之删除，已使用的小时照常计费，只停机不停实例的话费用会继续累积。

不管选哪家，下单前先想好备份方案，再把续费日期设个提醒，比事后补救省心得多。

## 常见问题

**RackNerd 的促销价续费会涨吗？**
不会。社区反馈和第三方测评都确认促销价续费同价，这也是它在低价 VPS 圈里口碑最稳的一点。

**优惠码怎么用，能和新购促销叠加吗？**
结账页填写即可。INTENSEINVESTOR 和 DRWOOKIEE 都是 30% 循环折扣，KVM VPS 月付年付通用，$11.29 的入门档用码还能再降一截，最终折扣以结账页显示为准。

**CloudCone 的洛杉矶机器现在还能放心用吗？**
事件后 CloudCone 已完成密钥轮换、访问加固，并迁移到自研虚拟化平台，密苏里和弗吉尼亚机房未受影响。但“受影响数据不可恢复”这一点说明：用任何预算 VPS，都要保留自己的异地备份。

**年付和按小时计费到底怎么选？**
服务器全年开机，年付便宜得多；一年里只断断续续跑几轮任务，按小时计费更划算——注意 CloudCone SC2 部署前要预存约一个月的估算费用。
